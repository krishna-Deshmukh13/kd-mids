Practical 2 — Text Classification using KNN

🎯
Aim: Text classification for sentimental analysis using KNN algorithm on the IMDB dataset.
🧠 KNN Algorithm — How It Works Theory

K-Nearest Neighbors is a simple supervised learning algorithm. It stores all training data and classifies a new point based on similarity to its K nearest neighbors.

1️⃣
Select K (number of neighbors) — typically K=5
↓
2️⃣
Calculate Euclidean distance from new point to all training points
↓
3️⃣
Take K nearest neighbors based on calculated distance
↓
4️⃣
Count data points in each category among those K neighbors
↓
5️⃣
Assign new point to category with maximum neighbors
↓
6️⃣
Model is ready to predict!

Step 3 Load Dataset & Preprocess Text

Cell [3–4]
# Load IMDB dataset (has 'review' and 'sentiment' columns)
df = pd.read_csv('IMDB Dataset.csv')

# Initialize tools
stop_words = set(stopwords.words('english'))
lemmatizer = WordNetLemmatizer()

# Text preprocessing function
def preprocess_text(text):
    tokens = word_tokenize(text)              # 1. Tokenize
    tokens = [w for w in tokens
               if w.lower() not in stop_words]  # 2. Remove stopwords
    tokens = [lemmatizer.lemmatize(w.lower())
               for w in tokens]               # 3. Lemmatize
    return ' '.join(tokens)

# Apply preprocessing to all reviews
df['review'] = df['review'].apply(preprocess_text)

# Encode labels: positive=1, negative=0
le = preprocessing.LabelEncoder()
df['sentiment'] = le.fit_transform(df['sentiment'])

# Convert text to numbers using TF-IDF
vectorizer = TfidfVectorizer(max_features=5000)
X_train_bow = vectorizer.fit_transform(X_train)
X_test_bow  = vectorizer.transform(X_test)

# Train KNN Classifier with K=5
clf = KNeighborsClassifier(n_neighbors=5)
clf.fit(X_train_bow, y_train)

Practical 3 — Polarity-based Document Classification

🎯
Aim: Write a program to recognize whether a document is positive or negative based on polarity words using Naive Bayes classification.
📋 What is Polarity Classification? Theory

Polarity classification identifies whether text expresses a positive, negative, or neutral sentiment. It uses a predefined list of polarity words — counting positive vs negative words to decide.

✅ Positive Words

good, happy, excellent, awesome, amazing

❌ Negative Words

bad, sad, terrible, awful, disappointing

💻 Complete Code

Step 1 Imports & Dataset

Cell [5–6]
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.metrics import accuracy_score, classification_report

# Load dataset (has 'Comments' and 'Category' columns)
data = pd.read_csv('companyfeedback.csv')

Step 2 Define Polarity Words & Classify Function

Cell [7, 10]
# Define polarity word lists
positive_words = ["good", "happy", "excellent", "awesome", "amazing"]
negative_words = ["bad", "sad", "terrible", "awful", "disappointing"]

# Function to classify based on polarity word count
def classify_document(document):
    pos_count = sum(1 for word in document.split()
                    if word in positive_words)
    neg_count = sum(1 for word in document.split()
                    if word in negative_words)
    if pos_count > neg_count:   return 'positive'
    elif neg_count > pos_count: return 'negative'
    else:                         return 'neutral'

# Apply to dataset
data['predicted_sentiment'] = data['Comments'].apply(classify_document)

Step 3 Train Naive Bayes Model

Cell [16–22]
# Split dataset
X_train, X_test, y_train, y_test = train_test_split(
    data['Comments'], data['Category'],
    test_size=0.2, random_state=42)

# Convert text to numerical features using CountVectorizer
vectorizer = CountVectorizer()
X_train_counts = vectorizer.fit_transform(X_train)
X_test_counts  = vectorizer.transform(X_test)

# Train Multinomial Naive Bayes classifier
classifier = MultinomialNB()
classifier.fit(X_train_counts, y_train)

# Predict & Evaluate
y_pred = classifier.predict(X_test_counts)
accuracy = accuracy_score(y_test, y_pred)
report   = classification_report(y_test, y_pred)

print(f'Accuracy: {accuracy:.2f}')   # 0.62
print('Classification Report:\n', report)
💡
Naive Bayes vs KNN: Naive Bayes works on probability (Bayes theorem), assuming features are independent. KNN works on distance. Naive Bayes is faster for text classification.

About the warnings: "Precision and F-score are ill-defined" — this means some categories had no predicted samples. It's normal when dataset is small. Add zero_division=0 to suppress.

💻 Complete K-Means Code

Step 1 Setup Points & Distance Functions

Cell [1–2]
import numpy as np
import matplotlib.pyplot as plt
import math

# Define the 8 data points
x = np.array([0.1,0.15,0.08,0.16,0.2,0.25,0.24,0.3])
y = np.array([0.6,0.71,0.9,0.85,0.3,0.5,0.1,0.2])

# Plot all points
plt.plot(x,y,"o")
plt.show()

# Distance functions
def euclidean_distance(x1,y1,x2,y2):
    return math.sqrt((x1-x2)**2+(y1-y2)**2)

def manhattan_distance(x1,y1,x2,y2):
    return math.fabs(x1-x2)+math.fabs(y1-y2)

Step 2 Cluster Assignment Function

Cell [3]
# Returns 1 if point closer to m1, else 2
def returnCluster(m1, m2, x_co, y_co):
    d1 = manhattan_distance(m1[0], m1[1], x_co, y_co)
    d2 = manhattan_distance(m2[0], m2[1], x_co, y_co)
    if d1 < d2:  return 1
    else:         return 2

Step 3 K-Means Iteration Loop

Cell [4]
# Initial centroids: M1=P1, M2=P8
m1 = [0.1, 0.6]
m2 = [0.3, 0.2]

difference = math.inf   # Start with infinity
threshold  = 0.02       # Stop when change is tiny
iteration  = 0

while difference > threshold:
    print("Iteration", iteration, "m1=",m1, "m2=",m2)
    cluster1, cluster2 = [], []

    # STEP 1: Assign each point to nearest centroid
    for i in range(0, np.size(x)):
        num = returnCluster(m1, m2, x[i], y[i])
        point = [x[i], y[i]]
        if num == 1:  cluster1.append(point)
        else:         cluster2.append(point)

    print("Cluster 1:", cluster1)
    print("Cluster 2:", cluster2)

    # STEP 2: Recalculate centroids (mean of cluster)
    m1_old = m1
    m1 = np.mean(cluster1, axis=0)  # axis=0 = column-wise mean
    m2_old = m2
    m2 = np.mean(cluster2, axis=0)

    # STEP 3: Calculate difference (convergence check)
    xAvg = (math.fabs(m1[0]-m1_old[0]) + math.fabs(m2[0]-m2_old[0])) / 2
    yAvg = (math.fabs(m1[1]-m1_old[1]) + math.fabs(m2[1]-m2_old[1])) / 2
    difference = xAvg if xAvg > yAvg else yAvg
    print("Difference:", difference)
    iteration += 1

# Final Output
print("Cluster 1 centroid: m1 =", m1)
print("Cluster 1 points:", cluster1)
print("Cluster 2 centroid: m2 =", m2)
print("Cluster 2 points:", cluster2)

Step 4 Plot Clusters

Cell [5]
clust1 = np.array(cluster1)
clust2 = np.array(cluster2)

plt.scatter(clust1[:,0], clust1[:,1])       # Cluster 1 points
plt.scatter(clust2[:,0], clust2[:,1])       # Cluster 2 points
plt.scatter([m1[0],m2[0]], [m1[1],m2[1]], marker="*")  # Centroids
plt.show()

Cluster 2 centroid: m2 = [0.2475, 0.275]
Cluster 2 points: P5[0.2,0.3], P6[0.25,0.5], P7[0.24,0.1], P8[0.3,0.2]

Key Theory Concepts

KNN Algorithm — Complete Theory
  • 🔵 Full form: K-Nearest Neighbors
  • 🔵 Type: Non-parametric, supervised learning classifier
  • 🔵 Uses: Both classification AND regression (mostly classification)
  • 🔵 Principle: Uses proximity (distance) to make predictions
  • 🔵 Distance metric: Euclidean distance = √[(x2-x1)² + (y2-y1)²]
  • 🔵 Advantages: Simple, no training phase, non-parametric
  • 🔵 Disadvantage: Slow for large datasets, sensitive to irrelevant features
K-Means Clustering — Complete Theory
  • 🟣 Type: Unsupervised machine learning algorithm
  • 🟣 Goal: Partition dataset into K clusters
  • 🟣 Works by: Iteratively assigning points to nearest centroid & updating centroids
  • 🟣 Convergence: Stops when centroids stop moving (difference < threshold)
  • 🟣 SSE: Sum of Squared Errors — measures total distance from each point to its centroid. Lower = better
  • 🟣 Initial centroids matter: Different starting centroids can give different results
NLP Concepts (for Practicals 2 & 3)
  • Tokenization: Breaking text into smaller units (words, sentences)
  • Stopwords: Common words with little meaning (the, a, is, are)
  • Lemmatization: Reducing words to their root form (running→run)
  • TF-IDF: Numerical representation of text importance
  • CountVectorizer: Counts word frequency in each document
  • Sentiment Analysis: Determining positive/negative/neutral opinion in text
  • NER: Named Entity Recognition — finds names, places, etc.
  • Confusion Matrix: Table showing TP, FP, TN, FN predictions

📚 Practical 1 — Pre-processing

What is data pre-processing? Why is it needed?▼
Data pre-processing is a technique to convert raw data into a clean, usable dataset. It is needed because real-world data is often collected in raw format with missing values, inconsistencies, and noise — which cannot be directly used by machine learning algorithms. Without pre-processing, the algorithm's output will be inaccurate.
What are the 6 steps of data pre-processing?▼
1. Import Libraries   2. Import/Load Data   3. Check for Missing Values   4. Arrange/Encode Categorical Data   5. Do Scaling   6. Distribute into Training, Validation, and Test Sets
How do you handle missing values in a dataset?▼
Two main approaches: 1. Remove rows containing missing values using dropna() — but this risks losing important data. 2. Impute values by filling with mean (for numerical like Age), median, or mode (for categorical like Embarked). Example: df['Age'].fillna(df['Age'].mean())
What is Label Encoding? Why did we encode the Sex column?▼
Label Encoding converts categorical text values to numerical values. We encoded Sex because machine learning modules cannot understand text — they only process numbers. male→1, female→0 using: df['Sex'].apply(lambda x: 1 if x == 'male' else 0)
What does data.info() and data.shape return?▼
data.shape returns a tuple (rows, columns) — for Titanic it's (891, 12). data.info() returns detailed info: column names, non-null counts, and data types. This helps identify which columns have missing values.
What percentage of males vs females survived the Titanic?▼
From the dataset: ~18.9% of males survived and ~74.2% of females survived. This shows females had a much higher survival rate — consistent with "women and children first" policy.

🤖 Practical 2 — KNN

What is the KNN algorithm? How does it work?▼
KNN (K-Nearest Neighbors) is a non-parametric, supervised learning algorithm. It stores all training data and classifies a new point by finding the K closest training points (using Euclidean distance) and assigning the majority class. Steps: Select K → Calculate distances → Find K nearest → Count votes → Assign majority class.
What is TF-IDF? Why is it used for text classification?▼
TF-IDF stands for Term Frequency-Inverse Document Frequency. It converts text to numbers by measuring: TF = how often a word appears in a document; IDF = how rare the word is across all documents. High TF-IDF means the word is important and unique to that document. We use it because KNN needs numerical input — not raw text.
What is lemmatization? How is it different from stemming?▼
Lemmatization reduces a word to its dictionary root (lemma): "running"→"run", "better"→"good". Stemming just chops off suffixes: "running"→"runn". Lemmatization is more accurate as it uses vocabulary and morphological analysis, while stemming is faster but cruder.
What are advantages of KNN?▼
1. Simple and easy to implement   2. No training phase (lazy learner)   3. Non-parametric (no assumptions about data distribution)   4. Naturally handles multi-class problems. Disadvantages: Slow for large datasets, memory intensive, sensitive to irrelevant features.

📊 Practical 3 — Polarity

What is sentiment analysis? What are its applications?▼
Sentiment analysis is the process of drawing meaning from text to identify the emotional tone — positive, negative, or neutral. Applications: 1. Social media monitoring   2. Product review analysis   3. Customer feedback classification   4. Stock market prediction   5. Political analysis
What is Naive Bayes? Why is it good for text classification?▼
Naive Bayes is a probabilistic classifier based on Bayes' theorem, assuming all features are independent (naive assumption). It's good for text classification because: 1. Works well with high-dimensional data (many words)   2. Fast to train   3. Requires little training data   4. CountVectorizer + MultinomialNB is a classic NLP pipeline.
What is a Confusion Matrix? Explain TP, FP, TN, FN.▼
A confusion matrix shows actual vs predicted classifications. TP (True Positive): Correctly predicted positive   TN (True Negative): Correctly predicted negative   FP (False Positive): Predicted positive but actually negative (Type I error)   FN (False Negative): Predicted negative but actually positive (Type II error). Accuracy = (TP+TN)/(Total)

🔵 Practical 4 — K-Means

What is K-Means clustering? How is it different from KNN?▼
K-Means is an UNSUPERVISED algorithm — no labels needed. It groups data into K clusters by minimizing distance to centroids. KNN is a SUPERVISED algorithm — needs labeled training data. KNN classifies; K-Means clusters. K-Means updates centroids iteratively; KNN just stores training data.
What is SSE in K-Means? What does it indicate?▼
SSE (Sum of Squared Errors) measures the total distance between each data point and its assigned cluster centroid. Lower SSE = better clustering (points are closer to their centroids). For our practical, SSE = 0.045. It helps evaluate clustering quality and choose the optimal K value using the "Elbow method".
Why does initial centroid selection matter in K-Means?▼
Initial centroids significantly impact the final clustering result. Poor initial centroids can lead to: 1. Local optima (not the best grouping)   2. Slow convergence   3. Different clusters every run. Solution: Use K-Means++ initialization (sklearn's default) which spreads initial centroids far apart, giving better results.
Which cluster does P6 belong to and why?▼
P6 = [0.25, 0.5] belongs to Cluster 2 (C2) after convergence. Manhattan distance from P6 to M1=[0.1,0.6]: |0.25-0.1|+|0.5-0.6| = 0.15+0.1 = 0.25. Manhattan distance from P6 to M2=[0.3,0.2]: |0.25-0.3|+|0.5-0.2| = 0.05+0.3 = 0.35. Since distance to M1 < M2, P6 goes to Cluster 1. (Note: Check your notebook output — results may vary slightly based on iteration.)

  • SSE = Σ distance² of each point to centroid

📈 Evaluation Metrics

  • Accuracy = (TP+TN) / Total
  • Precision = TP / (TP+FP)
  • Recall = TP / (TP+FN)
  • F1-Score = 2 × (P×R)/(P+R)
  • confusion_matrix(y_test, y_pred)
  • classification_report(y_test, y_pred)
